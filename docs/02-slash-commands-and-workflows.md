# 02. 斜杠命令、多智能体与自动化调度

合理使用内置斜杠命令（Slash Commands）与后台编排能力，可以将 Antigravity 从“单轮问答助手”升级为“多角色工程团队”。

---

## 一、常用斜杠命令（Slash Commands）速查

在 Chat Canvas 输入 `/` 即可唤起命令菜单（部分命令属于特定内置扩展/工作流）：

| 命令 | 适用场景 | 核心技巧 |
| :--- | :--- | :--- |
| **`/plan`** | 复杂架构改造或跨模块开发 | 先输出完整分步方案，审阅确认后再执行，避免返工 |
| **`/grill-me`** | 需求模糊、存在多种技术选型时 | 让 Agent 通过多轮交互式提问把边界条件和设计决策对齐 |
| **`/goal`** | 耗时较长的无人值守任务（如通宵重构/修复） | 指示 Agent 保持高彻底性，在目标完全达成前不提前停下 |
| **`/boost`** | 高难度研发或深度调研任务 | 启用更深度的思考、战略规划、多视角交叉验证与严格校验 |
| **`/compact`** | 对话轮次过多、上下文接近上限时 | 主动压缩并总结当前对话上下文，释放窗口空间同时保留关键结论 |
| **`/schedule`** | 需要定时巡检或延迟提醒时 | 配置 Cron 周期任务或一次性计时器，到期自动唤醒 Agent |
| **`/browser`** | 需要操作网页、抓取或端到端 Web 测试时 | 唤起浏览器自动化能力与网页交互 |
| **`/teamwork`** | 大型项目需要多智能体分工协作时 | 启动多 Agent 协作模式 |
| **`/learn`** | 刚纠正过 Agent 错误或摸索出复杂环境配置时 | 将本次经验沉淀固化，避免后续对话重复踩坑 |

> [!TIP]
> 在终端 CLI (`agy`) 中，可随时输入 `/help` 查看当前版本支持的全部斜杠命令。

## 二、Subagent（子智能体）使用技巧

当主对话需要处理**独立分支任务**或**大量只读检索**时，使用 Subagent 可以避免主上下文被海量搜索结果污染：

1. **职责分离**：
   - `research`（只读沙箱、无网络）：适合大范围代码库普查、文档检索，不污染主对话上下文。
   - `self`（继承完整工具与权限）：适合独立可并行的开发/测试子任务。
   - 自定义 Subagent：可按需限制是否开启写工具（`EnableWriteTools`）、MCP 工具或嵌套子智能体。
2. **工作区隔离模式（Workspace Mode）**：
   - `inherit`：与父智能体共享当前工作区（适合只读或串行任务）。
   - `share`：共享底层仓库存储但拥有独立工作副本（类似 `git worktree`，适合多作者并行改代码且节省磁盘）。
   - `branch`：完全独立的克隆分支工作区（适合高风险实验）。
3. **异步通知，无需轮询**：
   Subagent 在后台运行，完成后会自动通过消息机制唤醒主智能体，无需写循环去轮询状态。

## 三、Workflow 脚本编排（`run_workflow`）

当任务天然可以拆成**代码化的扇出（Fan-out）/ 流水线（Pipeline）**时（例如：对 50 个模块逐一做安全审计再汇总、多角度并发代码审查），使用 Python Workflow 脚本比手动一个个派发 Subagent 更稳定高效。

- **适用判断**：
  - 单个委托任务 → 用 **Subagent**。
  - 大量同构子任务并发、多阶段数据流转、结果聚合过滤 → 用 **Workflow**（借助 `agent`、`parallel`、`pipeline`、`phase` 原语）。

## 四、定时与后台任务（Schedule & Background）

- **One-shot Timer（一次性计时器）**：支持配合触发条件（`TimerCondition`），例如等待某子智能体或后台任务消息到达时提前取消计时并唤醒。
- **Cron 周期任务**：支持标准 5 段 Cron 表达式；默认带随机抖动（jitter）防止负载尖峰，仅在严格要求整点对齐时开启精确时间（`ExactTiming`）。
- **切忌用 `sleep` 替代计时器**：长等待应交给系统的 `schedule` 工具，让当前回合结束并释放资源，等待事件驱动唤醒。
